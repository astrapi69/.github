# .github

Default community health files for the public repositories of astrapi69. GitHub offers them in every repository of the
account that has no files of its own of the same kind ("Creating a default community health file",
https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

- `.github/ISSUE_TEMPLATE/`: the issue forms Bug, Improvement and Decision and `config.yml`, after rule AG-114 of
  https://github.com/astrapi69/astrapi69/blob/main/rules/core/git-and-prs.md. A repository that keeps any file in its
  own `.github/ISSUE_TEMPLATE` folder uses none of these.
